# 菲阿里四价 — 纯规则研究快照（BTC / ETH / SOL）

这是同一套 PURE 引擎在 Binance USDT-M 1h/1d 上的结果，覆盖大约 2023-07-01 至 2026-09-27，分割日 UTC 2025-10-07（前 70% / 后 30%）。
仓库里没有附带 K 线。要自己重跑，见同目录 `README.md`。

黄金、PAXG、XAU 不在这份结果里，也不在本仓库的菲阿里代码路径里。

## 规则

- 昨日四价：YO 开盘、YC 收盘、YH 最高、YL 最低。信号只用 YH / YL。
- 做多：当天第一根 high > YH 的 1h。开盘已经高于 YH 就按开盘价，否则按 YH。
- 做空：当天第一根 low < YL 的 1h。成交价镜像。
- 不看开盘相对昨收的方向，没有 1.5R 止盈，没有盘中止损。
- 每个标的每天最多一笔。同一根 K 线两边都破则当天不做。
- 出场只用当天最后一根 1h 的收盘价。R：多单 entry−YL，空单 YH−entry。每笔风险为当时权益的 1%，起点 $10,000。
- 往返费用 0.05%，另外给了 0.08% 的对照。日末平仓，资金费按 0 计。
