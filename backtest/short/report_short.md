# 短线震荡/均值回归策略回测（预注册，独立于趋势引擎）

- 方案与通过标准见 `PLAN.md`（2026-09-29 12:59 CST 写入，早于第一次运行 12:59:53）。三个候选参数全部预先固定，**没有调参、没有网格搜索**，本报告的数字全部来自第一次、也是唯一一次正式运行（`short_output.txt`）。
- 代码：`short.py`（回测）、`short_report.py`（生成表格与图）。数据：长数据 = `../data_long`（Binance/OKX，2023-10 → 2026-09），HL = `../data`（2026-03 → 09）。
- 撮合口径：只挂 maker 限价，价格需穿过限价 ≥1 tick 才成交、按限价成交；止损 stop-market + 0.02% 滑点 + taker；止盈 maker 限价、入场当根不止盈；同根止损与止盈都可达时算止损；资金费按小时实际费率；风险 0.5–0.75%/笔，单仓名义 ≤3× 权益，总名义 ≤10×。

## 结论

1. **三个候选全部未通过预注册标准**，长数据 4 币、实盘 3 币、HL 6 个月数据上都是亏损：A −42.9%（PF 0.68）、B −23.5%（PF 0.70）、C −52.0%（PF 0.88）（长数据 4 币）。样本内和样本外同样亏（IS PF 0.72 / 0.72 / 0.89，OOS PF 0.61 / 0.68 / 0.87），不是过拟合后失效，而是规则本身没有正期望。
2. **这次问题不在手续费**：手续费只占毛利 6–9%（标准要求 <30%，三者都满足）。maker 入场 + 宽止损（≥2×ATR / 0.6%）确实把 V1/V2 那种「费用吃掉一切」的问题解决了，但剩下的毛利本身就是负的：均值回归平均 R 为 −0.05 ~ −0.22。
3. **在 2024Q2–Q4 震荡段也不赚钱**：A −14.8%、B −3.0%、C −27.8%。想要的「趋势亏时它赚」没有出现。
4. **与 L0 月收益正相关，不是对冲**：长数据 +0.40 / +0.12 / +0.46，HL 数据 +0.69 / +0.29 / +0.59。在这套数据里，逆势挂单和趋势跟踪往往在同样的行情里一起亏。
5. **合并预览（L0 + C 各半，C 按预注册规则以样本内 PF 最高入选）**：+83.3%、MDD 47.5%，比 L0 单独（+218.6%、MDD 51.8%）回撤只降 4 个点、收益少一大半。**不值得合并。**
6. 相对最好的是 **B（4h 区间边缘）**：亏损最小、相关性最低（+0.12），2025H2 +6.2%（PF 1.48），但全期 PF 0.70、MDD 23.5%，达不到任何接近通过的程度。按预注册规则**不应该在这批数据上继续调它的参数**；如果要试，需要换一段数据做样本内（例如只用 2023-10 → 2025-09 调，再看 2025-09 之后）。
7. 建议：短期不要把这三种震荡策略接入实盘；现有实盘 MR（3 年 1 笔）也没有证据值得保留或放宽。

## 结果稳健性自查

- **入场当根止损**（A 38 笔、B 9、C 206）：买限价在开盘价下方、止损又在限价下方，只要该根最低价 ≤ 止损，价格必然先穿过限价再到止损，所以这是**确定发生**的，不是保守假设。
- **同根止损与止盈都可达**（按止损处理）：A 0 次、B 2 次、C 9 次，影响可忽略。
- 以上两项说明亏损不是撮合假设造成的。

## 注意事项

- 只有 1h K 线，没有逐笔/盘口；「穿价 1 tick 才成交」没有模拟排队位置，在薄盘口可能仍偏乐观，在厚盘口偏悲观。跳空穿过限价时仍按限价成交（略偏悲观）。
- 长数据不是 Hyperliquid：价格差很小，但资金费约为 HL 的一半或更低；HYPE 约 2025-04 起才参与，2025-02→05 资金费用 BTC 代理。
- HL 数据只有约 7 个月，月收益相关系数只基于 7 个点，参考价值很低；长数据约 36 个点。
- 3 币组合的「与 L0 相关」是和 **4 币 L0** 曲线比较（没有单独跑 3 币 L0 的 HL 版本）。
- 单一历史路径；三个候选只是这个方向里的三组具体规则，不能证明「所有」震荡策略都无效。
