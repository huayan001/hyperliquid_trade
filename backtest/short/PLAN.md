# 短线震荡/均值回归策略 —— 预注册方案（写于看任何结果之前，2026-09-29 12:59 CST）

目标：在趋势引擎亏钱的震荡期（如 2024Q2–Q4）赚钱、与 L0 趋势收益低相关的独立短线策略。独立于 hl_bot 趋势/现有 MR 引擎，只复用 `hl_bot.indicators`（EMA/ADX/ATR/BB/RSI/Donchian）。
参数全部在此固定，**不做任何网格搜索**；本轮不做任何参数选择（若将来要调参，只能在样本内调，报告样本外）。

## 通用规则（三个候选相同）

- 数据：`BT_DATA=long`（2023-10-01 → 2026-09-28，BTC/ETH/SOL Binance、HYPE OKX；HYPE 约 2025-04 起）+ HL 近 6 个月数据（2026-03-20 → 2026-09-29）
- 主结果：4 币组合（BTC/ETH/SOL/HYPE）；附：实盘标的 ETH/SOL/HYPE 组合
- 初始 $1000，共享权益；每个候选单独回测；每币同时最多 1 仓
- 信号只在已收盘 K 线上计算（1h 收盘；4h/1d 只用已收盘 K），挂单从**下一根 1h** 开始生效
- 入场：**只挂 maker 限价单**。买单只有当该根 1h 最低价 ≤ 限价 − 1 tick 才成交（卖单：最高价 ≥ 限价 + 1 tick），成交价 = 限价（不假设更优价），maker 费 0.015%。tick：BTC 1、ETH 0.1、SOL 0.01、HYPE 0.001
- 止损：stop-market，触发即按 min(止损价, 开盘价)（空单 max）成交，再加 0.02% 滑点，taker 费 0.045%
- 止盈：resting maker 限价，同样要求穿价 ≥ 1 tick，成交价 = 限价，maker 费；**入场当根不允许止盈**（只能从下一根起）
- 同一根 K 内：入场与止损都可能触发时，假定入场后被止损（保守）；止损与止盈都可能触发时，假定先止损（保守）
- 时间止损 / 条件离场：在 1h 收盘判定，下一根开盘市价离场（taker + 滑点）
- 资金费：按小时实际费率（与 bt.py 相同口径）
- 仓位：风险 = risk_pct × 权益（按成交这根的开盘价估值）/ 止损距离；单仓名义 ≤ 3× 权益；全部仓位名义合计 ≤ 10× 权益（10x 杠杆上限）；最小名义 $10
- 止损后冷却：同币 4 根 1h（B：下一根 4h 收盘前不再发信号）
- 期末按最后收盘价平仓

## 候选 A —— 1h 布林带回归 + 非趋势过滤

- 过滤：日线 ADX(14) < 22.5（即 hl_bot.regime 不会判为「趋势明确」）且 4h ADX(14) < 25
- 做多信号（1h 收盘）：收盘 < BB(20,2) 下轨 且 RSI(14) < 35；做空对称（收盘 > 上轨 且 RSI > 65）
- 入场：限价 = 收盘 ∓ 0.25×ATR(14,1h)，有效 3 根 1h
- 止损：入场 ∓ max(2.0×ATR1h, 0.6%×入场价)
- 止盈：BB 中轨（每根收盘更新，下一根生效）；若信号时 (中轨 − 入场) < 0.5×止损距离则不下单
- 时间止损：持仓 24 根 1h
- 风险 0.75%

## 候选 B —— 4h Donchian 区间边缘回归

- 在每根 4h 收盘计算：U/L = 最近 30 根 4h（含当根）最高/最低，W = U − L
- 过滤：4h ADX(14) < 20、日线 ADX(14) < 25、W ≥ 4×ATR(14,4h)、区间稳定 W / W(12 根 4h 前) ∈ [0.8, 1.25]
- 做多：4h 收盘 ≤ L + 0.25W → 买限价 L + 0.10W；做空：收盘 ≥ U − 0.25W → 卖限价 U − 0.10W；有效 16 根 1h
- 止损：L − 0.5×ATR4h（空：U + 0.5×ATR4h）
- 止盈：区间中点 (U+L)/2（固定）
- 挂单期间任一 4h 收盘落在 [L, U] 之外 → 撤单
- 时间止损：72 根 1h
- 风险 0.75%

## 候选 C —— 日线趋势内的 RSI(2) 回调

- 过滤：日线 EMA20 > EMA50 且日线 ADX ≥ 20 → 只做多；EMA20 < EMA50 且 ADX ≥ 20 → 只做空
- 信号（1h 收盘）：RSI(2) < 10（做多）/ > 90（做空）
- 入场：限价 = 收盘 ∓ 0.2×ATR1h，有效 2 根 1h
- 止损：入场 ∓ max(1.5×ATR1h, 0.6%)；止盈：入场 ± 1.2×ATR1h；时间止损 12 根 1h
- 风险 0.5%
