# v1.1 策略规则 → 代码对照

本文说明两份研究文档如何落到实现，避免「文档一套、代码另一套」。

| 规则 | 文档 | 代码 |
|---|---|---|
| 环境路由：日线趋势 / 1h 震荡 / 中间或冲突观望 | 两份文档第 6 节 | `hl_bot/regime.py`：`decide_from_metrics` / `route_regime` |
| 趋势入场：4h Donchian20 **收盘**突破 | 趋势 2.3 | `strategies/trend.py` |
| **禁止**等回撤到 EMA 再进 | 趋势 0 / 2.1 / 2.3 | `forbid_ema_pullback=True`，入场条件不含 EMA 距离 |
| BTC 突破 K 实体 > 1.5×ATR → 市价/紧限价追；止损仍 2×ATR | 趋势 2.3.1 | `chase_symbols` + `chase_body_atr` |
| 做空非对称：仅空头环境；BTC 空 ADX>25 且风险×0.7 | 趋势 0 / 2.3.2 | 趋势模块 + `risk.py` |
| 趋势止损 2×ATR、移动止损、EMA/ADX 失效离场 | 趋势 2.4 | `TrendStrategy.generate_exits` |
| 震荡：BB(20,2)+RSI(14)+VWAP，必须反转确认 K | 均值回归 3 | `strategies/mean_reversion.py` |
| ADX>25 / 区间收盘突破 / 带宽高位+实体>1.5×ATR 停开 | 均值回归 2 | `expansion_halt` |
| 环境破坏提前离场、时间止损 4–6h、中轨先平 50% | 均值回归 3.4 | `MeanReversionStrategy.generate_exits` |
| 仓位 = 风险预算 / 止损距离；杠杆反推；逐仓思维 | 两份文档第 3/4 节 | `risk.py` `derive_position_size` |
| 禁止马丁/同向加仓 | 均值回归 4.2；本 PR 非目标 | `RiskManager.evaluate_open` |
| 默认 dry-run，密钥只走环境变量 | 产品范围 | `config.py` / `.env.example` |

参数默认值见仓库根目录 `config.toml`，与文档建议区间一致（取中值，如趋势单笔风险 1.5%、震荡 0.75%）。
