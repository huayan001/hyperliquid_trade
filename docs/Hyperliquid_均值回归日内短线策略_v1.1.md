# Hyperliquid 均值回归日内/短线交易策略研究

**交易标的**：BTC、ETH、SOL、HYPE
**策略类型**：均值回归（震荡区间操作）
**持仓周期**：日内到短线（几十分钟到1–2天，不做波段持仓）
**杠杆风格**：待定，本文档默认给出中等杠杆（3–5x）建议，具体请结合下方"仓位管理"章节自行调整
**版本**：v1.1（相对 v1.0：强化「急涨不接刀/不停用」、明确与趋势策略分工、做空在震荡内保留）
**配套**：与《Hyperliquid_趋势跟踪波段策略》配套使用，两套策略互为对立场景的补充

> ⚠️ 研究/教育性质，不构成投资建议。均值回归策略在真正的趋势行情中会持续逆势加仓被打止损，务必严格执行"环境过滤"规则，不能凭感觉判断"是不是在震荡"。

## 1. 为什么均值回归适合日内/短线，而不是波段

均值回归的假设是"价格偏离均值后会回归均值"，这个假设**只在无明显趋势的震荡区间内成立**。一旦行情进入趋势（比如趋势跟踪策略里 ADX>20 的环境），均值回归会系统性亏钱——因为价格会持续"偏离"而不回归。

结合 Hyperliquid 的机制，均值回归天然更适合日内/短线，而不是波段持仓：

- **资金费率按小时结算**：如果你能在同一小时内完成开仓+平仓（比如快速的日内反转交易），可以完全不产生资金费成本。这是均值回归高频进出的一个隐性优势，波段策略反而享受不到。
- **震荡区间通常不会持续太久**：加密货币市场大部分时间是"趋势市"，真正干净的震荡区间往往维持几小时到1-2天就会被突破，持仓周期拉长到"波段"反而更容易正好撞上区间被打破的时刻。
- **手续费敏感**：日内高频进出对 Maker/Taker 费率更敏感，本策略默认全部使用限价单（Maker，约0.015%）挂在关键位置，而不是市价单抢入场。

**与 BTC「急涨」的关系**：BTC 常见一根大阳远离均线。那种行情是趋势/动量，**不是**均值回归的入场机会。本策略的「等反转确认K线」是为了避免在震荡假跌破时接刀，**不是**用来等急涨回撤后再追多。急涨追多见趋势策略 v1.1。

## 2. 环境过滤：先判断"现在是不是震荡市"

这是均值回归策略**最重要**的一步，比入场信号本身更重要。

| 过滤条件 | 参数建议 | 说明 |
|---|---|---|
| ADX(14)，1小时图 | ADX < 20 | ADX 走低代表没有明显趋势，是震荡市的必要条件 |
| 布林带宽度（Bollinger Bandwidth） | 处于近20期的中低位（非扩张阶段） | 布林带持续收窄/走平，代表价格在区间内滚动，而不是趋势性扩张 |
| 近期高低点结构 | 近8–12小时价格在同一个区间内反复触及上下沿，未创新高新低 | 直接确认"区间"是否存在，比指标更直观 |

**启用规则**：只有当 ADX < 20 **且** 价格结构确认处于横向区间时，才启用均值回归策略。

**立即停用新开仓（v1.1 强化）**，满足任一即停：

- ADX 回升超过 25，或
- 价格突破区间边界并收盘站稳，或
- 布林带宽度进入近 20 期高位区且单根 K 实体 > 1.5×ATR（典型急涨/急跌启动）

停用后切换到观望，或把执行权交给趋势跟踪逻辑；**不得**在扩张行情里继续挂均值回归单。

## 3. 入场信号

### 3.1 核心指标组合

| 指标 | 参数 | 作用 |
|---|---|---|
| 布林带 | 20期，2倍标准差 | 定义区间上下轨，作为反转交易的触发边界 |
| RSI | 14期 | 确认超买超卖，避免只靠触及布林带边缘就入场 |
| VWAP（当日成交量加权均价） | 日内滚动计算 | 作为"均值"的参考锚点，比单纯均线更贴近真实成交重心 |

### 3.2 入场规则（做多）

1. **环境确认**：按第2节规则确认当前处于震荡区间（ADX<20 + 区间结构确认），且未触发停用条件。
2. **超卖触发**：价格触及或跌破布林带下轨，且 RSI(14) < 30。
3. **反转确认**（避免接刀，**保留**）：等待出现一根明确的反转K线信号（如长下影线锤子线，或收盘价重新收回布林带下轨之上），不在触及下轨的当根K线立即入场，用"确认"换取更高胜率。
4. **入场价位**：优先使用限价单挂在布林带下轨附近或反转确认K线的低点上方一点，而不是市价追入，降低手续费和滑点成本。

### 3.3 入场规则（做空，震荡内对称保留）

与做多对称，**在震荡环境内保留做空**：

1. 环境确认同上。
2. 价格触及或升破布林带上轨，且 RSI(14) > 70。
3. 出现明确的反转K线（如长上影、收盘重新回到上轨之下），不在触及上轨当根K线追空。
4. 限价单挂在上轨附近或确认K高点下方一点。

说明：此处做空是「区间上沿均值回归」，**不是**趋势跟踪里的破位追空。趋势空单只在趋势策略、且仅在空头环境下执行。

### 3.4 离场规则

- **目标位1（保守）**：价格回归 VWAP 或布林带中轨，先平掉50%仓位锁定利润。
- **目标位2（进阶）**：剩余仓位持有至触及布林带对侧边界，或 RSI 回到对侧极值区时全部离场。
- **止损**：入场价外侧一个"近期区间极值"或 1×ATR（取更保守的一个），一旦跌破/升破意味着"区间假设"已经失效，不要抱有"等它回来"的心态扛单。
- **时间止损（重要）**：如果开仓后 4–6 小时价格既没有触发止损也没有回归均值（横盘不动或缓慢逆势），主动离场——均值回归策略的资金效率依赖于"快进快出"，长时间不兑现的仓位会拖累整体资金费/机会成本。
- **环境破坏提前离场（v1.1）**：持仓期间若 ADX 上冲 > 25，或布林带进入扩张态，或出现实体 > 1.5×ATR 的突破K，**优先按市价/限价主动平仓**，不要死等硬止损——这正是 BTC 急涨打穿震荡空单/急跌打穿震荡多单的典型场景。
- **资金费率异常飙升（机器人默认启用）**：若持仓方向持续付费且年化（或 24h 均年化）≥ `mean_reversion.funding_annual_exit`（默认 50%），可市价提前离场。该阈值属于均值回归自己的配置，不复用趋势的 `funding_annual_warn`。

## 4. 仓位管理与杠杆

均值回归策略的胜率通常较高，但单次盈亏比偏低（赢多次小赢，一旦遇到趋势突破可能是一次较大的亏损），仓位管理的核心是**控制"黑天鹅式趋势突破"对账户的冲击**：

### 4.1 单笔风险预算

- 每笔交易账户风险仍控制在 **0.5%–1%**（比趋势跟踪策略更低，因为均值回归的止损逻辑在假突破行情下更容易被连续打穿）。
- 杠杆倒推公式与趋势策略一致：
  ```
  仓位名义价值 = (账户资金 × 单笔风险比例) / 止损距离百分比
  ```
- 默认杠杆区间建议 **3–5x**：均值回归策略靠"高频次+高胜率"积累收益，不需要靠高杠杆放大单笔收益，过高杠杆反而会在偶发的趋势突破行情中被迅速爆仓。

### 4.2 组合层面限制

- **单标的同一方向不加仓**：均值回归策略不使用"越跌越买"的马丁格尔式加仓，一旦止损即为止损，不摊低成本。
- **同时最大持仓数**：BTC/ETH/SOL/HYPE 最多同时开 2 个方向不同或不相关时段的仓位，避免四者同步被同一次突破行情打穿。
- **日内最大交易次数上限**：建议单日单标的不超过3-4次开仓，避免情绪化频繁进出（尤其是止损后想立刻"报仇式"再次入场）。
- **单日最大回撤触发停止交易**：账户单日浮亏达到3%时，当日停止新开仓，等待次日重新评估环境。

### 4.3 Isolated 保证金

同样建议逐仓（Isolated），单笔止损金额=计划投入保证金，不追加保证金"扛单"。

## 5. 执行清单（Checklist）

**开仓前：**
- [ ] 1小时图 ADX < 20，价格结构确认处于横向区间
- [ ] 布林带宽度非扩张；无实体 > 1.5×ATR 的急涨/急跌启动K
- [ ] 价格触及布林带边缘 + RSI 超买/超卖
- [ ] 出现反转确认K线（不接刀；**不做**「无确认追急涨」）
- [ ] 用限价单挂单，降低手续费
- [ ] 止损设在区间外/1×ATR，风险≤0.5–1%账户资金
- [ ] Isolated保证金，杠杆控制在3–5x

**持仓中：**
- [ ] 到达VWAP/中轨先减仓50%锁定利润
- [ ] 4–6小时未兑现则时间止损离场
- [ ] 持仓期间监控ADX/带宽；若趋势突然走强(ADX上冲>25)或急涨急跌启动，**提前离场**而非等硬止损

**复盘：**
- [ ] 记录每笔交易环境过滤是否准确（是否真的在震荡区）
- [ ] 统计因「未及时停用」被急涨/急跌打穿的次数，用于收紧第2节停用条件
- [ ] 统计胜率、平均盈亏比、假突破被打穿次数，用于优化环境过滤参数

## 6. 与趋势跟踪策略的配合方式

两套策略本质上是**互斥的环境判断**，实盘中建议合并成一套"环境路由"逻辑：

```
判断 ADX / 结构：
  若日线趋势明确（EMA 方向一致且 ADX > 20~25）→ 启用趋势跟踪（含 BTC 急涨追突破；空头环境才开趋势空）
  若 1h ADX < 20 且区间结构成立           → 启用均值回归（含震荡内做空；保留反转确认）
  中间地带（20附近）或信号冲突            → 观望，不新开仓
```

这样可以避免：

- 用均值回归逻辑硬扛趋势行情（含 BTC 急涨）
- 用趋势跟踪逻辑在震荡市追假突破
- 把「等反转确认」误用成「等急涨回撤再追」

## 7. 风险提示

- 均值回归策略在识别"假突破"（区间被突破后又快速拉回）和"真突破"（趋势正式开始）之间天然存在滞后，环境过滤规则无法100%准确，连续误判会导致连续止损。
- BTC 急涨/急跌对震荡空单/多单极不友好；v1.1 的停用与提前离场规则必须写进机器人，不能只靠人工盯盘。
- 日内高频操作对执行速度、手续费、滑点更敏感，建议先在模拟盘充分验证下单延迟和实际成交价与理论价的差异。
- Hyperliquid 的资金费率、手续费档位、杠杆上限均可能调整，请以实盘App数据为准。
- 本文档不构成投资建议，仅为策略研究框架。
