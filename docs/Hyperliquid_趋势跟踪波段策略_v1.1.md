# Hyperliquid 趋势跟踪波段交易策略研究

**交易标的**：BTC、ETH、SOL、HYPE（少数高流动性品种）
**策略类型**：趋势跟踪（追涨杀跌）
**持仓周期**：波段（几天到几周）
**杠杆风格**：较高杠杆（5–10x+）
**版本**：v1.1（相对 v1.0：明确「不回撤等入场」、BTC 急涨追突破、做空非对称）
**配套**：与《Hyperliquid_均值回归日内短线策略》配套，两套策略互为对立场景的补充

> ⚠️ 本文档为研究/教育性质的策略框架整理，不构成投资建议。加密货币永续合约在高杠杆下风险极大，可能导致本金全部损失，请务必先用小仓位/模拟盘验证后再实盘执行。

## 1. 平台机制要点（策略设计的约束条件）

在设计策略前，先明确 Hyperliquid 的几个关键机制，因为它们直接决定了策略的仓位管理和成本结构：

- **手续费**：Base 档位 Taker 约 0.045%、Maker 约 0.015%，随 14 天滚动交易量提升可降档，HYPE 质押还有额外折扣。高频进出会明显侵蚀波段策略的收益，因此本策略更倾向使用限价单（Maker）入场；**BTC 急涨追突破例外**（见 2.3.1）。
- **资金费率（Funding）**：**按小时结算**（不是主流交易所常见的 8 小时），费率 = 溢价部分 + 利率部分。正常行情下大致在 0.001%–0.012%/小时的区间浮动，折算年化可能从个位数到上百不等；极端行情下可能快速走高。**这对"波段持仓几天到几周"的策略是重要成本项**，尤其是 SOL、HYPE 这类波动较大的标的，资金费率往往更高更不稳定。
- **杠杆上限**：按标的分档，且随仓位名义价值增大而收紧（保证金分层）。大致参考（具体以 App 内实时显示为准，会调整）：
  - BTC：上限较高（各资料显示 40x 甚至 50x，但大仓位会被分层压低）
  - ETH：上限次之（约 25x 附近）
  - SOL：上限更低（约 20x 附近）
  - HYPE：作为山寨币，上限通常明显更低（个位数到十几倍不等）
  - **实操建议**：不要以"标称最大杠杆"做仓位规划，而是用"分层后的有效杠杆"倒推可用杠杆，并始终把爆仓价距离作为仓位管理的核心变量，而不是名义杠杆倍数本身。
- **保证金模式**：Cross（默认，全仓共享保证金）vs Isolated（逐仓，风险隔离）。**本策略建议对每个标的使用逐仓（Isolated）**，避免单一标的爆仓拖累整个账户，尤其是在同时持有 BTC/ETH/SOL/HYPE 多个仓位时。
- **最小下单量**：约按 $10 名义价值计算，各标的对应的最小币量不同，下单前需核对当前价格换算。

## 2. 策略核心逻辑：多周期趋势跟踪

### 2.1 设计思路

趋势跟踪策略的本质是"承认自己无法预测顶底，只顺着已确认的趋势方向交易，靠少数大趋势的盈利覆盖多次小止损"。在波段周期（数天到数周）下，建议采用**双周期确认**框架：

- **大周期（日线级）**：判断主趋势方向，过滤掉高杠杆下最致命的"逆势重仓"。
- **小周期（4小时级）**：寻找顺势的入场时机，提高入场价格效率、缩小止损距离。

**与「等回撤」的关系**：本策略是突破跟随，不是回调买入。BTC 常见「急涨后价格远离均线」——若强制等回撤到 EMA，会系统性错过主升段。回撤接多留给别的策略或后续版本；v1.1 **明确禁止**把「价格回到 EMA 再进」写成硬规则。

### 2.2 趋势判断指标组合

| 指标 | 参数建议 | 作用 |
|---|---|---|
| EMA 双线 | EMA20 / EMA50（日线） | 判断主趋势方向：EMA20 在 EMA50 上方=多头趋势，反之空头 |
| ADX（趋势强度） | ADX(14) > 20~25 | 过滤震荡市，只在趋势"确实存在"时交易，避免在盘整区反复被打止损 |
| Donchian 通道突破 | 20 日高/低点突破（4小时图执行） | 作为顺势方向上的具体入场触发信号（突破近期高点做多 / 突破近期低点做空） |
| ATR（平均真实波幅） | ATR(14) | 用于止损距离和仓位大小的动态计算，替代固定百分比止损 |

### 2.3 入场规则

#### 2.3.1 做多（多头环境）

1. **趋势过滤**：日线 EMA20 > EMA50，且 ADX(14) > 20 → 判定为多头趋势环境，**只允许做多，不做空**。
2. **入场触发**：4 小时图价格突破近 20 根 K 线高点（Donchian 上轨），且突破 K 线**收盘价站稳**（不用影线，用收盘确认，减少假突破）。**不要求**价格回撤到 EMA20/EMA50 后再入场。
3. **BTC 急涨追突破（专用）**：
   - 当突破 K 线实体长度 > 1.5×ATR(14)（4h）时，视为动量急涨；
   - 允许在收盘确认后用**市价单**或挂在突破价附近的**紧限价**追入，不再优先等待更深回撤或更远 Maker 挂单；
   - 止损仍为入场价 − 2×ATR，仓位仍按单笔风险预算反推，不因追价而放大风险百分比；
   - ETH/SOL/HYPE 默认仍优先 Maker 限价；仅 BTC（或后续回测验证后扩展的标的）启用本条。
4. **资金费率过滤**：入场前检查当前及过去 24 小时平均资金费率。若做多方向资金费率年化已 > 50%（多头持仓需持续付费给空头），需下调该笔交易的目标仓位或缩短预期持仓周期，因为持仓成本会显著侵蚀波段收益。
5. **多标的共振加分（可选）**：如果 BTC、ETH、SOL、HYPE 中有多个标的同时出现同方向趋势信号，可视为"市场级趋势"，适度提高该方向的整体风险预算；但要注意四者高度相关，本质上是同一个 Beta 的不同放大器，不能当作"分散化"。

#### 2.3.2 做空（空头环境，非对称）

做空**需要保留**，但与做多不对等执行：

1. **趋势过滤（更严）**：日线 EMA20 < EMA50，且 ADX(14) > 20（**BTC 建议 ADX > 25**）→ 判定为空头趋势环境，只允许做空，不做多。
2. **入场触发**：4 小时图价格跌破近 20 根 K 线低点（Donchian 下轨），且突破 K 线收盘确认。同样**不要求**反弹到 EMA 再空。
3. **仓位非对称**：同一账户风险规则下，BTC 空单的单笔风险预算按多单的 **约 70%** 计算（例如多单 1.5% 则空单约 1.05%）；其他标的可先与多单同档，回测后再调。
4. **资金费率**：若做空方向需持续支付高额资金费（空头付费），同样下调仓位或缩短持仓预期。
5. **禁止**：多头环境（EMA20 > EMA50）下开趋势空；「感觉涨多了」不是开空理由。

### 2.4 离场规则

- **初始止损**：入场价 − 2×ATR（做多）/ 入场价 + 2×ATR（做空），并用 Isolated 保证金 + 该止损距离反推实际使用杠杆。
- **移动止损（Trailing Stop）**：价格每向有利方向运行 1×ATR，止损上移/下移 0.5×ATR，锁定浮盈，让趋势继续跑。
- **趋势失效离场**：若日线 EMA20 重新跌破/升破 EMA50，或 ADX 明显回落至 15 以下（趋势衰竭信号），无论盈亏主动离场，不等硬止损打到。
- **金字塔加仓（可选，进阶）**：若首仓盈利达到 1×ATR 以上且趋势指标继续确认，可加仓不超过首仓 50% 的仓位，止损同步上移至保本以上，控制整体风险不因加仓而扩大。急涨追突破成交的首仓，加仓规则可更保守或暂不加仓，直至浮盈覆盖追价滑点。

## 3. 仓位管理与杠杆使用（风险控制核心）

高杠杆（5–10x+）策略最容易翻车的地方**不是信号本身，而是仓位管理**，务必优先执行以下规则：

### 3.1 单笔风险预算

- 每笔交易的**账户风险**（止损被打到时的实际损失）固定为账户总资金的 **1%–2%**（BTC 空单按该值的约 70%），不随杠杆倍数变化。
- 计算方式：
  ```
  仓位名义价值 = (账户资金 × 单笔风险比例) / (止损距离百分比)
  实际杠杆 = 仓位名义价值 / 实际投入保证金
  ```
- 也就是说，**杠杆倍数是止损距离和风险预算共同推导出的结果**，不是主观先定好"用8倍"然后再找止损位——这是高杠杆策略最常见的致命错误。

### 3.2 组合层面限制

- **同时最大持仓数**：BTC/ETH/SOL/HYPE 最多同时开 2–3 个方向一致的仓位（因四者相关性很高，同时开满 4 个约等于把风险预算集中下注在同一个方向上）。
- **账户总风险敞口上限**：所有未平仓位加总的潜在止损损失，不超过账户总资金的 **6%**。
- **单日/单周最大回撤触发降杠杆**：若账户在单日内浮亏达到 5%，或单周浮亏达到 10%，当日/当周新开仓的杠杆倍数减半，直到回撤修复。
- **资金费率成本纳入盈亏预估**：波段持仓若预计持有 3–7 天，需提前用当前资金费率估算"持仓期总资金费成本"，并计入盈亏预期（尤其 SOL、HYPE 的资金费率历史上波动更大）。

### 3.3 逐仓（Isolated）保证金的具体用法

- 每个标的单独开逐仓仓位，保证金额度 = 该笔交易计划投入的最大风险金额对应的保证金，**不额外追加保证金去"救"已经逆势的仓位**——触发止损就是止损，追加保证金延后爆仓等于把风险管理规则本身推翻。

## 4. 执行清单（Checklist）

**开仓前：**
- [ ] 日线 EMA20/EMA50 方向一致，ADX(14) > 20（BTC 做空建议 ADX > 25）
- [ ] 多头环境只做多 / 空头环境只做空（不做逆势）
- [ ] 4小时 Donchian 突破且收盘确认；**未**把「回撤到 EMA」当作入场条件
- [ ] BTC 且突破 K 实体 > 1.5×ATR → 允许市价/紧限价追突破；否则优先 Maker
- [ ] 查看当前/24h资金费率，评估持仓成本
- [ ] 用 ATR 算出止损距离 → 反推仓位大小和实际杠杆（BTC 空单风险预算 ×0.7）
- [ ] 确认单笔风险 ≤ 1–2%账户资金，组合总风险 ≤ 6%
- [ ] 设置为 Isolated 保证金，挂好止损单（不依赖"手动及时止损"）

**持仓中：**
- [ ] 按 ATR 规则移动止损
- [ ] 每日检查一次资金费率变化，异常飙升时重新评估是否提前离场
- [ ] 趋势指标（EMA/ADX）失效信号出现即离场，不等硬止损

**复盘：**
- [ ] 记录每笔交易的信号触发条件、是否追突破、实际杠杆、资金费成本、盈亏结果
- [ ] 分开统计多单 vs 空单、BTC 追突破 vs 普通突破的胜率与盈亏比
- [ ] 按周/月统计胜率、盈亏比、最大回撤，用于后续参数迭代

## 5. 回测与验证建议

1. **先用历史K线数据回测信号本身**（EMA/ADX/Donchian 组合），在不考虑资金费率和手续费的情况下先看趋势跟踪逻辑本身的胜率/盈亏比是否成立。
2. **单独回测「等 EMA 回撤入场」对照组**：预期在 BTC 急涨样本上显著跑输「收盘突破即进」，用以验证 v1.1 禁止等回撤的决策。
3. **再叠加真实成本**：把 Hyperliquid 的 Taker/Maker 手续费、历史资金费率数据代入回测；BTC 追突破样本需按 Taker 费率计成本。
4. **小资金实盘/模拟盘验证 4–8 周**，观察实际滑点、爆仓价计算是否与理论一致，再逐步放大仓位。
5. **参数不要过度优化（过拟合）**：EMA/ADX/ATR 的参数没有"标准答案"，重点是规则本身要能长期稳定执行，而不是找到历史回测中"最优"的一组参数。

## 6. 与均值回归策略的环境路由

```
判断 ADX / 趋势结构：
  若日线趋势明确（EMA 方向一致且 ADX > 20~25）→ 启用本趋势跟踪策略
  若 1h ADX < 20 且区间结构成立           → 启用均值回归策略
  中间地带 / 冲突信号                     → 观望，不新开仓
```

急涨行情归趋势侧处理；**不要**用均值回归的「等反转确认」去追 BTC 主升。

## 7. 风险提示

- 加密货币永续合约波动剧烈，5–10x 甚至更高杠杆下，短时间的价格波动即可导致强制平仓，本金可能全部损失。
- 市价追突破会提高手续费与滑点，急涨后假突破止损也可能更痛；必须用固定风险百分比约束仓位。
- Hyperliquid 的杠杆上限、保证金分层规则、资金费率结构等**均可能随时调整**，实盘前请以 App 内实时数据为准，不要依赖本文档中的具体数字。
- 本文档不构成任何投资建议，仅为策略研究框架，请根据自身风险承受能力谨慎决策。
